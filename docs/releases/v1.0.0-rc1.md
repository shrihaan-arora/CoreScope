## Overview

CoreScope is a native, dependency-free macOS hardware observability tool designed specifically for Apple Silicon Macs. It reads live power-management unit (PMU) die temperatures, operating device thermal nodes, battery telemetry, and AC/DC power-source states on demand via Apple's native system frameworks.

This release candidate introduces the Midnight Liquid Glass user interface, user-controlled Thermal Sessions with live Swift Charts, safe local ambient asset resolution, in-memory privacy controls, and a reproducible standalone application packaging and notarization pipeline.

---

## Verified Capabilities

### 1. PMU Hardware Thermal Observability
- Enumerates thermal nodes using private `IOHIDEventSystemClient` APIs (`0xFF00:0x05`) resolved dynamically against system IOKit.
- Accurately classifies readings into dedicated hardware categories:
  - **Silicon Die (`tdie`)**: Compute complex thermal sensors across CPU/GPU cores and SoC fabric.
  - **Device Node (`tdev`)**: Peripheral power-management thermal nodes across the logic board.
  - **Battery (`battery` / `gas gauge`)**: Battery pack thermal sensors.
  - **Storage (`nand` / `storage`)**: NVMe and NAND flash storage controller sensors.
  - **Calibration / Reference (`tcal`)**: Reference channels reported by Apple PMU firmware, strictly isolated from operating die averages.
- Calculates true die average and peak temperatures exclusively from validated silicon die channels.

### 2. User-Controlled Thermal Sessions
- Optional periodic recording with a documented **2.0-second sampling interval** active only while a session is running.
- Selectable session durations: **30 seconds**, **2 minutes**, **5 minutes**, or **Manual stop**.
- Live hardware die temperature timeline rendered via native **Swift Charts** with monotone spline interpolation:
  - Amber line for peak die temperature.
  - Teal line with soft vertical area gradient for average die temperature.
- Real-time elapsed and remaining countdown timers.
- Summary statistics card panel: peak observed temperature and sensor channel, average observed die temperature across samples, minimum die compute baseline, and total session duration.
- **Strict Non-Overlapping Probing**: `isSamplingInProgress` prevents concurrent hardware queries even if a reading stalls.
- **In-Memory Privacy Guarantee**: Zero database writes, zero automatic file generation, and zero background analytics. All recordings reside in volatile memory and are cleared when the session is cleared or the application quits.
- **Native CSV Export**: User-initiated export via macOS `NSSavePanel` adhering to RFC 4180 escaping. Strictly omits personal directories, machine identifiers, and serial numbers.

### 3. Power & Battery Status
- Samples power source modes (AC Power vs. Battery Discharge) via Apple's public `IOPowerSources` (`IOKit.ps`) API.
- Accurately reports battery percentage, charging state, adapter connection, and thermal pressure state without polling. Charging status is decoupled from adapter attachment.

### 4. Midnight Liquid Glass User Interface
- Modern glassmorphic visual hierarchy:
  - Near-black midnight background base (`#090B13`).
  - Static indigo-blue and violet ambient illumination pools (zero continuous animation CPU overhead).
  - Translucent floating cards with subtle specular edge highlights and violet tint.
  - High-contrast typography: pure white primary text and muted lavender secondary labels.
- Three-section native navigation: `Overview`, `Thermal Session`, and `Sensors` segmented tabs.
- Category filter tabs with live channel counts and real-time search filtering.
- Native macOS `AppIcon.icns` compiled from 1024×1024 liquid-glass squircle source artwork (`CoreScopeAppIcon.png`).

### 5. Safe Ambient Asset Loading & Resilient Fallback
- Replaced synthetic `Bundle.module` access with safe multi-candidate bundle resolution.
- Resolves `CoreScopeAmbient.png` directly from `Contents/Resources/` in packaged `.app` bundles, binary siblings, and development checkouts.
- Graceful `nil` fallback: If the ambient image is absent or invalid, the UI renders the native dark liquid-glass gradient without crashing or throwing assertions.

### 6. On-Demand Lifecycle & Process Cleanliness
- Stateless hardware scanning: Sensor handles are allocated strictly during a scan and released immediately upon completion.
- Zero continuous background polling or CPU overhead when idle (measured **0.0% CPU**).
- No launch daemons, login items, helper executables, or elevated root privileges (`sudo`).
- Process cleanly terminates when the window is closed (`applicationShouldTerminateAfterLastWindowClosed`).

## Known Limitations

1. **Undocumented Hardware Interfaces**: Apple does not publish official public SDK documentation or fixed schemas for PMU thermal sensor channels (`IOHIDEventSystemClient`). Channel names and availability may change across macOS major updates.
2. **Ad-Hoc Signing in Local Builds**: Binaries built via `scripts/package-app.sh` use ad-hoc signatures (`codesign --sign -`) intended solely for execution on the local compilation machine.
3. **Notarization Prerequisite**: Public distribution to external users requires Apple Developer ID signing and notarization via `scripts/notarize-app.sh`. Running an ad-hoc package on a different Mac will be blocked by macOS Gatekeeper unless built from source or officially notarized.
4. **Passive Thermal Reading**: CoreScope is an observability tool; it does not control fan speeds, throttle clock rates, or alter hardware power states.
